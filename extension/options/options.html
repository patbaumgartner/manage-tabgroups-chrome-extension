    Permissions & privacy

    tabs
    Reads the address and title of grouped tabs so they can be restored later.
    tabGroups
    Reads and recreates tab groups, including their name and colour.
    storage
    Stores saved sessions locally. Browser sync is never used.
    alarms
    Schedules the periodic automatic backup.

    The extension declares no host permissions, injects no scripts into web pages, and makes no network requests. Its content security policy blocks outbound connections entirely.
